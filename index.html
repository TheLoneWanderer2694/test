Setup & HTTPS Fixes

1. External Control Access: On your Roku, navigate to Settings > System > Advanced system settings > Control by mobile apps and set it to Network access (Permissive).

2. HTTPS Block ("Mixed Content"): Browsers block web pages loaded on https:// from making HTTP requests to local IP addresses.

  • Open this web page file directly in your browser (file:///...).
  • Or click the Site Settings padlock icon near the address bar and select Allow Insecure Content.

Setup & Network Guidance

1. Local Network Connection: Your device and Roku must be connected to the exact same Wi-Fi/LAN network.

2. External Control Protocol (ECP): Roku devices feature a built-in REST API on port 8060. Control requests are dispatched directly via POST requests (e.g. http://<roku-ip>:8060/keypress/Home).

3. Browser CORS Policy Notice: Browsers restrict cross-origin HTTP requests. This application uses standard web mode: 'no-cors' mode. The POST commands will successfully hit and execute on your Roku, even if browser status logs reflect an opaque response type.

4. Keyboard Shortcuts:

  • Arrow Keys : Navigation
  • Enter : OK / Select
  • Backspace : Back
  • Escape : Home
  • Space : Play / Pause
